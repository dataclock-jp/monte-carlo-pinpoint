クイックスタート

  1. ターミナルでサーバーを起動する 
    cd video2ai
python -m agent.webapp.run
  2. ブラウザで http://localhost:8765 を開く
  3. 右パネルの Settings を開き、API Key と API URL を設定する（取得方法）
  4. Goal 欄にやりたいことを入力する（例：「メモ帳を開いてHello Worldと入力する」）
  5. Dry Run をONにしたまま Start を押して動作を確認する
  6. 問題なければ Dry Run をOFFにして再度 Start — AIが実際に操作を開始する

API Key の取得方法

Desktop Agent は LLM Vision API を使って画面を解析します。以下のいずれかのプロバイダーから API Key を取得してください。

Google Gemini 無料枠あり おすすめ

コストを抑えて試すなら Gemini がおすすめです。無料枠で十分テストできます。

対応モデルgemini-2.5-flash、gemini-2.5-pro
API Key 取得https://aistudio.google.com/apikey
API URLhttps://generativelanguage.googleapis.com/v1beta/openai
料金Flash: 無料枠あり（1日1500リクエスト）/ Pro: 従量課金

取得手順

  1. Google AI Studio にアクセスし、Googleアカウントでログイン
  2. 「APIキーを作成」をクリック
  3. プロジェクトを選択（なければ新規作成）して「キーを作成」
  4. 表示された API Key（AIza... で始まる文字列）をコピー
  5. Desktop Agent の Settings に以下を入力:
    • API Key: コピーした API Key
    • API URL: https://generativelanguage.googleapis.com/v1beta/openai
    • Model: Gemini 2.5 Flash
Anthropic Claude 従量課金 高精度

画面解析の精度が高く、複雑な操作手順も正確に実行できます。有料プランならレート制限も余裕があります。

対応モデルclaude-opus-4-6、claude-sonnet-4-6、claude-haiku-4-5
API Key 取得https://console.anthropic.com/settings/keys
API URL設定不要（自動設定）
料金Sonnet: $3/1M入力 $15/1M出力 / Haiku: $0.80/1M入力 $4/1M出力 / Opus: $15/1M入力 $75/1M出力

取得手順

  1. Anthropic Console にアクセスし、アカウント作成・ログイン
  2. 左メニューの「API Keys」をクリック
  3. 「Create Key」をクリックし、名前を付けて作成
  4. 表示された API Key（sk-ant-... で始まる文字列）をコピー
  5. Desktop Agent の Settings に以下を入力:
    • API Key: コピーした API Key
    • API URL: 入力不要（Claude選択時は自動で非表示になります）
    • Model: Claude Sonnet 4.6（コスパ重視）または Claude Opus 4.6（最高精度）
初回は支払い方法の登録とクレジットのチャージ（$5〜）が必要です。
OpenAI (GPT-4o) 従量課金

高精度な画面解析が必要な場合に。

対応モデルgpt-4o、gpt-4o-mini
API Key 取得https://platform.openai.com/api-keys
API URL空欄でOK（デフォルトで https://api.openai.com）
料金GPT-4o: $2.50/1M入力 $10/1M出力 / Mini: $0.15/1M入力 $0.60/1M出力

取得手順

  1. OpenAI Platform でアカウント作成・ログイン
  2. 左メニューの「API keys」をクリック
  3. 「Create new secret key」をクリックし、名前を付けて作成
  4. 表示された API Key（sk-... で始まる文字列）をコピー
  5. Desktop Agent の Settings に以下を入力:
    • API Key: コピーした API Key
    • API URL: 空欄
    • Model: GPT-4o または GPT-4o Mini
初回は支払い方法の登録とクレジットのチャージ（$5〜）が必要です。
xAI Grok 無料枠あり
対応モデルgrok-3-mini
API Key 取得https://console.x.ai/
API URLhttps://api.x.ai/v1
料金毎月 $25 の無料クレジット付与

取得手順

  1. xAI Console にアクセスし、アカウント作成・ログイン
  2. ダッシュボードの「API Keys」から新しいキーを作成

設定項目

項目説明推奨値
Model使用するLLMモデルgemini-2.5-flash（コスパ重視）
API Keyプロバイダーから取得したキー-
API URLAPIエンドポイントプロバイダーにより異なる（上記参照）
Method画面変化の検知方式diff（高速）
Threshold変化として認識する感度（0〜1、小さいほど敏感）0.02
Interval画面キャプチャの間隔（秒）1.0
Max Steps最大ステップ数（0 = 無制限）0 または 20（テスト時）

設定はブラウザの localStorage に保存されるため、次回アクセス時も引き継がれます。

自律モード（AIが自動操作）

Goal を入力して Start すると、AIが画面を見ながら自動的にマウス・キーボード操作を実行します。

使い方

  1. Goal 欄に目標を具体的に入力する
  2. Dry Run ON で Start して、AIがどんな操作を提案するか確認
  3. 問題なければ Stop → Dry Run OFF → 再度 Start
  4. Pause で一時停止、Stop で完全停止

Goal の書き方のコツ

  • 具体的に: 「ファイルを保存」→「メモ帳でCtrl+Sを押してファイルを保存する」
  • 手順を含める: 「Excelのセル A1 に "Hello" と入力し、Enterキーを押す」
  • 完了条件を明示: 「...して、保存ダイアログが閉じるまで」

手動モード（画面クリックで操作）

エージェントを起動しなくても、画面プレビューを直接操作できます。

操作方法
クリック画面プレビュー上の操作したい場所をクリック
テキスト入力下部バーにテキストを入力して「Type」ボタン
キー入力下部バーにキー名を入力して「Key」ボタン（例: Return, ctrl+s, Escape）
スクロール「Scroll Up」「Scroll Down」ボタン

キー名の例

Return Escape Tab BackSpace Delete space ctrl+s ctrl+c ctrl+v ctrl+z alt+F4 ctrl+shift+s

安全機能

Dry Run モード

ヘッダーの Dry Run トグルを ON にすると、AIが操作を「提案」するだけで実際のマウス・キーボード操作は行われません。初回テストでは必ず ON にしてください。

安全ルール（上級者向け）

JSON ファイルで禁止領域・禁止キー・確認ダイアログを設定できます。

{
  "rules": [
    {
      "id": "no-taskbar",
      "type": "forbidden_region",
      "message": "タスクバーへの操作は禁止",
      "region": {"x1": 0, "y1": 1040, "x2": 1920, "y2": 1080}
    },
    {
      "id": "no-alt-f4",
      "type": "forbidden_key",
      "message": "Alt+F4 は禁止",
      "keys": ["alt+F4"]
    },
    {
      "id": "confirm-delete",
      "type": "keyword_confirm",
      "message": "削除操作を実行しますか？",
      "keywords": ["delete", "削除", "remove"],
      "fields": ["target", "reasoning"]
    }
  ]
}

Tips

  • 画面プレビューにブラウザ自身が映る: ブラウザを最小化するか、セカンドモニターに移動してください
  • 操作速度が遅い: Interval を小さくする（例: 0.5）と反応が速くなりますが、API コストが増えます
  • 誤操作を防ぐ: Max Steps を小さめ（10〜20）に設定し、段階的に進めてください
  • 変化検知が敏感すぎる: Threshold を上げてください（例: 0.05）
  • Action Log で動作を確認: 全ての操作とAIの判断がログに記録されます
  • ポート変更: python -m agent.webapp.run --port 9000
